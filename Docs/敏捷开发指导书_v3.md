# XU News AI RAG 项目开发指导书 v3.0
---

## 📋 项目概述

**项目名称**：XU News AI RAG - 基于AI的新闻问答系统  
**项目目标**：构建一个智能的新闻问答系统，支持语义搜索和RAG问答  
**技术栈**：Flask + Vue3 + LangChain + SQLite + FAISS + Ollama  
**开发周期**：19天（4个Sprint）  
**开发模式**：轻量敏捷 (Lightweight Agile)

---

## 🎯 敏捷开发流程说明

### 核心理念
- **快速迭代**：每个Sprint产出可演示的增量功能
- **持续测试**：测试驱动开发，每个功能都有对应测试
- **及时反馈**：每个Sprint结束进行回顾和调整
- **灵活调整**：根据实际情况动态调整计划

### Sprint结构
```
Sprint Planning（计划会） → Daily Standup（每日站会） → Development（开发） 
→ Testing（测试） → Sprint Review（评审） → Sprint Retrospective（回顾）
```

```python
# Backend/services/analytics_service.py
from sklearn.cluster import KMeans
from sklearn.feature_extraction.text import TfidfVectorizer
from collections import Counter

class AnalyticsService:
    def get_clustering_report(self):
        """生成聚类分析报告"""
        # 1. 获取所有知识库内容
        items = KnowledgeItem.query.all()
        texts = [item.content for item in items]
        
        # 2. TF-IDF向量化
        vectorizer = TfidfVectorizer(max_features=100)
        X = vectorizer.fit_transform(texts)
        
        # 3. KMeans聚类
        kmeans = KMeans(n_clusters=5)
        clusters = kmeans.fit_predict(X)
        
        # 4. 提取Top10关键词
        keywords = vectorizer.get_feature_names_out()
        keyword_scores = X.toarray().sum(axis=0)
        top_10 = sorted(
            zip(keywords, keyword_scores),
            key=lambda x: x[1],
            reverse=True
        )[:10]
        
        return {
            'top_10_keywords': [
                {'keyword': k, 'score': float(s)} 
                for k, s in top_10
            ],
            'cluster_distribution': Counter(clusters),
            'total_items': len(items)
        }
```

### 测试金字塔

```
        /\
       /E2E\     端到端测试（少量，高价值）
      /____\     - 完整用户流程
     /      \    
    / Integ \   集成测试（适量，关键路径）
   /________\   - API测试、服务集成
  /          \  
 /   Unit     \ 单元测试（大量，快速反馈）
/______________\ - 函数、类、组件
```

### 测试类型与工具

| 测试类型 | 工具 | 覆盖率目标 | 执行频率 |

| API测试 | Postman, pytest | 100% | 每个Sprint |

| 性能测试 | Artillery | 关键指标 | Sprint 4 |
| 安全测试 | OWASP ZAP | 无高危漏洞 | Sprint 4 |
